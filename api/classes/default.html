    Class default

    Rigid body physics simulation for ascii art/text. Uses opentype.js to get character paths from a font. Supports gravity, collisions, boundary behavior, and optional debugging.

          canvas: HTMLCanvasElement,
          font_url: string,
          color?: string,
          font_size?: number,
          segmenter?: string,
      ): default

      Creates a banner on the given canvas and begins observing its size and visibility. Call setup before spawning text to load the font.

      Parameters

      • canvas: HTMLCanvasElement

        Canvas on which the banner is rendered.

      • font_url: string

        URL of the font used to create the character, supports only WOFF/OTF/TTF type font and not WOFF2.

      • color: string = 'black'

        Color used when initializing the character cache.

      • font_size: number = 36

        Font size used to build character polygons.

      • segmenter: string = 'en'

        Locale used to split text into grapheme clusters.

      Returns default

      Throws

      If a 2D rendering context cannot be obtained.
